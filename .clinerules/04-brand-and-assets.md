# Branding Rules

## Live Android mark

Use the native VectorDrawable:
`feature/src/main/res/drawable/mission_control_mark.xml`

Visual ingredients:
- Obsidian-safe transparent/flat surface
- Electric Lime upload arrow + tray
- Orbit Violet orbital ring
- Signal Cyan telemetry nodes

## Rules

- Do not introduce placeholder logos.
- Do not create multiple competing logos.
- Do not use arbitrary gradients or 3D effects for the product mark.
- Keep the launcher foreground, splash, and onboarding aligned to the same mark.
- Preserve the existing resource name only when compatibility requires it.
- The old PNG may remain as a compatibility/historical asset, but new UI should prefer the vector mark.
