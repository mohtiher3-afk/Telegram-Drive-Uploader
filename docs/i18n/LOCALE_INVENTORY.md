# Locale Inventory

**Supported locales found:** English (`values`) and Arabic (`values-ar`). No additional language or in-app language selector was added.

| Area | Implementation | Locale-sensitive | Risk | Status |
|---|---|---:|---|---|

## Static Conclusion

The project has a two-locale baseline, equal English/Arabic string-key counts, and matching placeholder signatures. The repository does not support global localization beyond English and Arabic. User-generated filenames, Telegram chat names, technical IDs, URLs, URIs, and tokens must remain untouched.
