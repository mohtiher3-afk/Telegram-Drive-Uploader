# Bug Root-Cause Template

## Problem

Describe the user-visible or system-observed failure.

## Reproduction

List the exact non-sensitive environment and numbered steps.

## Expected Behavior

State the intended result.

## Actual Behavior

State the observed result, error, and evidence.

## Root Cause

Identify the confirmed technical cause and the boundary where it occurs.

## Fix

Describe the smallest change made and why it addresses the cause.

## Tests

List focused tests, regression tests, build, lint, security, TDLib, and device checks that were actually run. Use `NOT VERIFIED` when evidence is unavailable.

## Regression Risk

List affected areas and any remaining uncertainty.

## Release Impact

State whether a release is required, the candidate version/commit, rollback reference, and publication decision.
