# Pinterest Lucky Swaps Palette Reference

## Evidence boundary

The supplied Pinterest page identifies the source as a dashboard design by UI UX Bunker / @uixninja. The loaded browser view exposed the pin artwork and a short preview, not design tokens or source files. The values below are therefore visual approximations for semantic translation, not extracted brand assets or claims of pixel accuracy.

## Observable palette direction

| Reference observation | Safe semantic translation for Telegram Drive |
|---|---|
| Near-black charcoal base with a cool navy cast. | Dark `background` and `surface` become blue-black rather than plum-black. |
| Graph lines, focus contours, and selected UI use restrained electric periwinkle/cobalt. | `primary`, navigation selection, actionable buttons, and focus rings use a cool cobalt family. |
| Content panels are dark graphite with subtle blue-violet borders and low contrast elevation. | Glass `surfaceContainer` roles retain transparency but use blue-slate values rather than purple-brown values. |
| Small live/status signals use a muted teal-green. | Keep green limited to real success/active status indicators; do not make it the universal CTA color. |
| Text is soft near-white with gray-blue supporting copy. | Preserve high-contrast `on*` roles and use a cool blue-gray `onSurfaceVariant`. |

## Explicit non-transfers

The reference contains finance/gaming-style dashboard content. This work transfers only its color temperature, glass hierarchy, and restrained blue signal language. It does not transfer balances, levels, scores, transactions, reward UI, fake activity, or nonfunctional upload indicators.
