# Localization Terminology

English is the source language. Arabic translations below are approved for UI labels and messages only; they must not be applied to filenames, Telegram content, usernames, chat names, IDs, URLs, hashes, or other technical values.

| English source | Arabic UI term | Usage |
|---|---|---|
| Upload | رفع | Action and feature name |
| Uploading | جارٍ الرفع | Active transfer status |
| Uploaded | تم الرفع | Completed transfer status |
| Upload queue | قائمة الرفع | Queue title |
| Upload history | سجل الرفع | History title |
| Prepare videos | تجهيز الفيديوهات | Preparation screen |
| Select videos | اختيار الفيديوهات | Picker action |
| Destination | الوجهة | Telegram target |
| Select destination | اختيار الوجهة | Destination screen |
| Connect | اتصال | General action |
| Connect Telegram | الاتصال بتلقرام | Authentication title |
| Telegram connected | تم الاتصال بتلقرام | Authorized state |
| Telegram not connected | غير متصل بتلقرام | Unauthenticated state |
| Settings | الإعدادات | Settings title |
| History | السجل | Navigation label |
| Queue | القائمة | Navigation label when used alone |
| Schedule upload | جدولة الرفع | Scheduling action |
| Clear | مسح | Clear action |
| Selected | محدد | Selection state |
| Pause | إيقاف مؤقت | Upload action if exposed |
| Resume | استئناف | Upload action if exposed |
| Cancel | إلغاء | Upload action if exposed |
| Retry | إعادة المحاولة | Retry action |
| Remove video | إزالة الفيديو | File-list action |
| Completed | مكتمل | Status label |
| Pending | قيد الانتظار | Status/summary label |
| Failed | فشل | Status label |
| Back | رجوع | Navigation action |
| Skip | تخطي | Onboarding action |
| Continue | متابعة | Forward action |
| Dismiss | إغلاق | Dismiss action |

The terminology intentionally uses concise Modern Standard Arabic. Technical unit symbols such as `KB`, `MB`, `GB`, and `TB` remain unchanged. Telegram is transliterated as `تلقرام` consistently in UI prose, while Telegram usernames and chat names remain source content.
